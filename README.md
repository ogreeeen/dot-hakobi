# ドットはこび（個人用）

好きな写真を荒いドット絵に変換し、色ブロックをスロットに置いて
アリにピクセルを運び出させるパズルゲーム。

- 色数（4〜10色）と粗さ（粗い・ふつう・細かい）を画面上部で選べる
- スロット数は「色数−1」（3〜7個）
- ブロックは必ず解ける順番で生成
- 外側に面しているピクセルだけ運べる。全部運び出したらクリア
- スロットのブロックから0.3秒に1匹アリが出て、絵を迂回してピクセルを取りに行き、来た道を戻って穴に運ぶ
- 起動時に「撮影する／写真を選ぶ」を選ぶ（サンプル絵なし）

ゲーム本体は `app/src/main/assets/index.html`。GitHubにpushするとActionsがAPKを作り、Releases の `latest` に置く。
